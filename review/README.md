# Branded Review Pages

Each customer gets a clean public page such as:

`/review/customer-slug/`

The page can be customized with:
- Business name
- Logo or initials
- Brand colors
- Short thank-you message
- Direct Google review URL
- Eric Review Tap footer branding

The page must not ask customers to select a star rating before reaching Google or otherwise gate negative reviewers. Every customer receives the same direct path to leave an honest Google review.

The demo page lives at `/review/demo/`.
